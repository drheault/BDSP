How it works

inputs: name, label, unit, default, optional min/max (gives a slider) and param to link a project parameter.
formulas: evaluated in order; use earlier names, ** for powers, and sqrt, sin, cos, tan, atan, exp, log, abs, min, max, pi.
outputs: which names to show, with label, unit and decimals.
checks: boolean expressions shown as pass/fail.
chart: sweep a variable over a range and plot series expressions.
headline: text with {name} placeholders.

Formulas are checked before publishing: no file, network or Python access is possible, only arithmetic.
